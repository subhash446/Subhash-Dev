# Subhash Kumar Yadav — Portfolio

Personal portfolio for Subhash Kumar Yadav, final-year B.Tech Information Technology student at NIET, Greater Noida.

## Run locally
Open `index.html` in a browser. The site uses Tailwind CDN, Lucide Icons and Font Awesome via CDN.

## Included
- Responsive single-page portfolio
- About, Skills, Projects, Resume, Certifications and Contact sections
- GitHub and LinkedIn links
- Downloadable resume
- AJAX contact form powered by FormSubmit (no custom backend required)

## Contact form setup
- The form sends messages to `subhashyadav25177@gmail.com` through FormSubmit without opening the visitor's email app.
- On the first submission, FormSubmit sends an activation email to the receiving inbox. Open it and confirm the form once before expecting messages to arrive normally. Check Spam/Junk if needed.
- Test from the deployed website or a local HTTP server; do not test the contact form by opening `index.html` directly with a `file://` URL.
